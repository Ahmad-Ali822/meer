# UI Design Specification

## Visual direction

Design a compact Windows desktop utility around 1200 × 760.

Brand colors:

```text
Navy: #242078
Red: #EF1822
Gold: #F4B51C
Background: #F4F5F8
White: #FFFFFF
Text: #252838
Muted text: #666B7A
Border: #D7DAE3
Success: #168A5B
Error: #D92D20

Use Inter or Segoe UI.

Rules
Use the Meer Ilyas logo without distortion.
No sidebar.
No dashboard cards, charts or statistics.
No browser-style layout.
Use a simple application header.
Use large readable labels and inputs.
Use 6–8px rounded corners.
Use minimal shadows.
Gold is only a small accent.
No gradients, glassmorphism or illustrations.
Keep the invoice form compact and keyboard friendly.
Product Name is the widest table column.
Grand Total and Pending must be prominent.
Show visible hover, focus, disabled and error states.
Use short, subtle transitions only.
Improve Stitch only when it increases clarity, consistency or accessibility.
Keep all screens visually consistent.
