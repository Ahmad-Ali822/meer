# Cursor Instructions

Build an offline Windows desktop application named **Meer Ilyas Invoice System** using Tauri v2, React and TypeScript.

Before implementation, read:

- `docs/PRODUCT_SPEC.md`
- `docs/UI_DESIGN_SPEC.md`
- `docs/TECHNICAL_SPEC.md`
- `docs/IMPLEMENTATION_PHASES.md`
- Existing source code
- Every image inside `stitch-images/`

## Permanent rules

- This is a compact desktop utility, not a website or SaaS dashboard.
- No database, inventory, saved customers, saved products, reports or invoice history.
- Use Stitch images as visual references.
- Identify each screenshot from its filename and visual content.
- Preserve the approved layout, colors and UX. Improve it only when usability or consistency clearly benefits.
- Use the supplied Meer Ilyas logo and brand colors.
- Implement only one phase at a time.
- Do not implement features from future phases.
- Before coding, state which files will change.
- After each phase, run relevant tests, lint and type checking.
- Report what changed and any remaining issues.
- Stop and ask: “Phase N is complete. Shall I begin Phase N+1?”
- Never continue without explicit approval.
- Do not edit Cargo registry or downloaded dependency files.
- Do not add unrequested dependencies or features.
